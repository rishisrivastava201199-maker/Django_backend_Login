\# Django Backend Login System



A simple and secure user authentication system built with Django. This project demonstrates user login, authentication, session management, protected dashboard access, and logout functionality.



\## 🚀 Features



\- User login authentication

\- Django session-based authentication

\- Protected dashboard

\- Logout functionality

\- Django admin integration

\- Template-based frontend

\- SQLite database for local development

\- Clean Django project structure



\## 🛠️ Tech Stack



\- Python

\- Django

\- HTML

\- CSS

\- SQLite

\- Django Authentication System
